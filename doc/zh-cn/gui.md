# 界面

界面是一个原生 MyGo 应用（`cmd/nextcloud-mygo`、`internal/gui`），面向使用 Nextcloud MyGo 的人，按 `design/`
中的设计稿实现。它自己不保存任何同步状态：账号、目录、地址和待决事项归 SyncD 所有；界面显示 SyncD 报告的快照，
并通过 `internal/syncd` 向它发送命令。在 SyncD 完成之前，界面连接 `syncd.Mock`，它显示示例数据，并在每页顶部的
一行中注明。

## 线程与状态

`gui.App` 的每个字段只在主线程读写。视图在主线程运行；发给 SyncD 的命令在单独的 goroutine 中执行（`App.do`），
结果经 `App.later` 交回主线程，并重绘窗口和托盘。命令返回前，对应按钮保持禁用；失败以文字提示（toast）显示，
从不显示代码。界面自己的设置保存在 `%AppData%\Nextcloud-MyGo` 的 `gui.json` 中，原子写入；与同步有关的内容都不放在这里。

## 主窗口

- **标题栏：** 由视图绘制：标志、名称、拖动窗口的区域，以及 Windows 11 的标题栏按钮。
- **侧栏：** 第一个账号（打开“账号与目录”）、四个页面（“活动”上显示待处理数量）、设置，以及用圆点和文字表示的
  整体状态和正在使用的地址（打开“网络”）。整体状态取第一个成立的：已暂停、需要你处理（删除确认、等待确认或等待登录的目录）、
  正在同步、离线、已是最新。
- **概览：** 暂停同步 / 恢复同步和立即检查；同步当前在做什么，显示阶段和已完成的文件数，而不是编造的总量；
  正在使用的地址及原因；所有需要处理的事项，各带一个处理按钮；目录。
- **账号与目录：** 每个账号的登录状态、添加目录或在浏览器中登录，以及它的目录：路径、状态，以及打开、暂停或恢复、
  查看，菜单中的停止同步。移除目录或账号前会先询问，并说明两边的文件都会保留。
- **网络：** 自动或始终使用一个地址；账号的各个地址，正在使用的排在最前、已阻止的排在最后，每个都显示两步信任
  （已认可、已核验为同一服务器）；选用当前地址的原因；最近的切换。
- **活动：** 删除确认（多少文件、删除会往哪个方向进行、涉及哪些内容；先给出“在本机恢复这些文件”，只有在第二次询问后
  才在服务器上删除，以及稍后决定）；其他需要处理的事项；最近的记录，可筛选。

## 对话框

- **添加地址：** 第 1 步只查看地址，不发送任何凭据；第 2 步显示证书和服务器信息，并请用户明确授权；第 3 步核验
  由 SyncD 在认可后完成。证书无效的地址不能被认可。
- **询问：** 移除、停止和在服务器上删除都使用警告框，“取消”在前。

## 首次设置

在没有账号时代替各页面显示，“添加账号”时也会显示：你的服务器、登录（在浏览器中完成 Login Flow v2；界面永远看不到密码）、
目录（加密目录不能选择）、开始（“登录 Windows 时启动”和通知，默认都开启；可选添加其他地址）。点“开始同步”之前不会同步任何内容。
“添加目录”会为已有账号打开“目录”这一步。

## 设置

设置以覆盖在变暗窗口上的面板打开（侧栏齿轮）：左边是搜索和各页面（常规、通知、同步与存储、网络、关于与更新、诊断），
右边是页面，由若干分区的行组成，每行是图标块、标题和一句说明，以及它的控件。

| 页面 | 设置 |
|---|---|
| 常规 | 语言（跟随 Windows、English、简体中文）、外观、登录时启动、在托盘中启动、关闭按钮、添加另一个账号 |
| 通知 | 需要确认的删除、需要重新登录、冲突、更新 |
| 同步与存储 | 暂停所有目录；删除保护，始终开启 |
| 网络 | 指向“网络”页面的链接 |
| 关于与更新 | 更新、每天检查、自动安装（从不、空闲时、每天 03:00）、版本、源代码、开源许可 |
| 诊断 | 日志文件夹；支持包，由 SyncD 生成 |

## 托盘与关闭

- 单击托盘图标打开浮出面板（状态、需要处理的事项、目录、打开、暂停、立即检查、只关闭窗口、退出并停止同步）；右键单击以菜单形式
  提供相同的操作。两者调用的都是窗口所用的同一组方法。
- 关闭按钮默认把应用留在托盘中（第一次会提示），也可以在“常规”中改为关闭窗口；两种方式下 SyncD 都继续同步。只有“退出并停止同步”
  会停止它。
- 主窗口只在显示时存在。登录时启动且开启“在托盘中启动”时，应用只显示托盘图标。

## 更新

只有签名的发布版才能自我更新（`mygo.Updater.Enabled`）；其他版本会说明这一点。开启时每天检查一次。安装前先请 SyncD 到达
安全点（`PrepareUpdate`）；有文件正在传输或有删除在等用户确认时，安装会推迟。自动安装在电脑空闲 15 分钟后或 03:00 这一小时内
进行，取决于所选方式；失败过一次的安装在同一次运行中不再重试。

## 语言

字符串位于 `locales/en.json`（源）和 `locales/zh-Hans.json`；`go tool mygo
generate` 生成 `locales/catalog_gen.go`。繁体中文和日文随后补充。

## 测试

`go test ./internal/gui` 以两种外观、两种语言渲染每个页面和设置页面，并检查删除确认、在服务器上删除前的询问，以及“恢复同步”
不会撤销单个目录自己的暂停。设置 `SCREENSHOT_DIR` 后，它会把每个窗口写成 PNG，用于与 `design/` 对照。
