# 版本历史

## 0.1.0

首个发行版：Windows 11 测试版，每个架构（x64 和原生 ARM64）一个当前用户安装包。

- **一个账号，多个地址。** 每个账号可以有同一服务器的多个受信任地址（互联网、家庭网络、VPN）。
  地址只有在其服务器、TLS 证书和目录命名空间都验证通过后才为账号服务。SyncD 自动选择地址，或保持你固定的地址；
  只在两次同步周期之间切换，账号的所有目录一起切换。登录或证书失败会阻止该地址，任何评分都不能越过。
- **Nextcloud Desktop 引擎。** 发现、协调、传播和 journal 都来自上游 Nextcloud Desktop，加上 19 个小补丁，
  运行在 SyncD 中，SyncD 是当前用户的后台进程。界面（Go 和 MyGo）通过本地命名管道与其通信，协议 1.10；
  关闭窗口从不停止同步。
- **文件安全。** 删除保护会把大量或异常的删除留给你确认。未确认的上传、移动或删除通过重新发现恢复；
  服务器不可达或目录无法读取时绝不当作空。传输中被打断的修改会保留服务器上的上一版本（修改以分块上传发送）。
  移动因网络失败的本地改名保持新名字，之后再次发送。
- **多个账号**，每个账号多个目录；通过浏览器登录；应用密码的续期与撤销；服务器已满或响应慢时分别如实报告。
- **界面：**概览、账号与目录、网络、含删除确认的活动、设置、托盘及其浮出面板；英文和简体中文。
- **安装与更新：**当前用户安装包，可原地升级，并检查每个二进制文件与架构相符。应用内更新只安装用项目更新密钥签名的
  压缩包；在设置中打开之前保持关闭。

已知限制：

- 文件同步（`fullSync`）尚未声明为已验证：添加目录时会说明这一点，已是最新的目录显示"上次同步已完成"，
  而不是绿色状态。按需文件已构建但未提供（`virtualFiles`）。
- 安装包没有 Authenticode 签名，因此首次安装时 Windows SmartScreen 会警告。
- 只在一台原生 ARM64 机器上测试。x64 二进制在该机器上以模拟方式通过了测试；x64 安装包未在 x64 硬件上运行过。
- 未覆盖：真实睡眠与恢复（仅模拟）、24 小时运行（以 1 小时加速长时间测试代替）、严格的 VPN 出口、
  第二个 Windows 会话或用户、端到端加密目录、驱动器号被其他卷复用、手工恢复的 journal。
  开机自启在发布后检查。
- 删除保护按单个同步周期计数：分散在多个周期中的删除不会累加。
- 安全阻止（证书改变、服务器不是预期的那一个）会持续到 SyncD 重启。
- 一次 20 分钟测试运行中 SyncD 出现过一次访问冲突，此后约五小时的运行未能复现，原因未明。
- 本版本不包含 macOS。

版本：Nextcloud Desktop v35.0.3（引擎），针对 Nextcloud 服务器 35.0.2 及上一主版本 34.0.5 测试；
Go 1.27.4；MyGo v0.9.0；Qt 6.12.0；OpenSSL 3.6.5。
